# Small analysis scripts

1. Protein–protein / protein–ligand contact analysis and visualization using [GROMACS](https://www.gromacs.org/) built-in tools (`gmx_interaction.py`) or [GetContacts](https://getcontacts.github.io/) (`AQP_LIP_contacts.py`, `Get_Contacts_PPI.py`)
2. Multivariable time-series analysis and plotting (`GDE_update.ipynb`)
3. Simulation convergence checks (block analysis)
4. PyMOL and VMD visualization scripts
